# Metodologias de Mapeamento de Processos

O mapeamento de processos é uma disciplina voltada para entender, documentar, analisar e melhorar a forma como uma organização executa suas atividades. Ao longo dos anos surgiram diversas metodologias, cada uma com objetivos específicos.

A seguir estão as principais metodologias utilizadas no mercado.

## Visão Geral das Metodologias

| Metodologia | Objetivo | Melhor utilização |
|---|---|---|
| BPM (Business Process Management) | Gerenciar e melhorar processos continuamente | Organizações que desejam controlar processos de ponta a ponta |
| BPMN (Business Process Model and Notation) | Padronizar a representação gráfica dos processos | Documentação e automação de processos |
| Fluxograma Tradicional | Representar a sequência das atividades | Processos simples e treinamento |
| SIPOC | Visão macro do processo | Levantamento inicial de processos |
| Value Stream Mapping (VSM) | Mapear fluxo de valor e desperdícios | Lean Manufacturing e Lean Office |
| Lean | Eliminar desperdícios | Melhoria contínua |
| Six Sigma | Reduzir variabilidade e defeitos | Processos críticos e de alta qualidade |
| DMAIC | Método estruturado do Six Sigma | Projetos de melhoria |
| Kaizen | Melhorias pequenas e contínuas | Cultura de melhoria |
| IDEF0 / IDEF3 | Modelagem funcional e de processos | Engenharia de sistemas e governo |
| EPC (Event-driven Process Chain) | Modelagem orientada a eventos | Ambientes SAP |
| UML Activity Diagram | Modelagem de fluxo de atividades de software | Desenvolvimento de sistemas |
| TOGAF | Arquitetura corporativa | Grandes organizações |
| APQC PCF | Modelo de referência de processos | Benchmark organizacional |
| SCOR | Cadeia de suprimentos | Logística e Supply Chain |

---

## 1. BPM (Business Process Management)

É a metodologia mais difundida atualmente.

Seu objetivo é gerenciar o ciclo de vida completo dos processos:

1. Descoberta
2. Modelagem
3. Análise
4. Implementação
5. Monitoramento
6. Melhoria contínua

Normalmente utiliza softwares BPMS.

### Vantagens

- Governança
- Indicadores
- Automação
- Integração com sistemas

## 2. BPMN

Não é exatamente uma metodologia.

É uma notação gráfica internacional utilizada para desenhar processos.

Possui elementos como:

- Eventos
- Atividades
- Gateways
- Pools
- Lanes
- Mensagens
- Subprocessos

É hoje o padrão mais utilizado para documentação empresarial.

Ideal quando existe interesse em automação posterior.

## 3. Fluxograma Tradicional

É o método mais antigo.

Utiliza símbolos simples:

- Início/Fim
- Processo
- Decisão
- Documento
- Entrada/Saída

Muito utilizado em:

- Procedimentos
- POPs
- Manuais
- Treinamentos

É simples, porém limitado para processos complexos.

## 4. SIPOC

Muito usado antes do detalhamento do processo.

SIPOC significa:

- **S**upplier (Fornecedor)
- **I**nput (Entrada)
- **P**rocess (Processo)
- **O**utput (Saída)
- **C**ustomer (Cliente)

Exemplo:

> Fornecedor → Dados → Cadastro → Cliente cadastrado → Usuário

Fornece uma visão executiva do processo.

## 5. Value Stream Mapping (VSM)

Ferramenta originada do Lean.

Mapeia:

- Fluxo de materiais
- Fluxo de informações
- Tempo de espera
- Tempo de processamento
- Estoques
- Gargalos

Muito utilizada em:

- Indústria
- Saúde
- Escritórios
- Serviços

## 6. Lean

Baseia-se na eliminação dos desperdícios.

Os desperdícios clássicos incluem:

| Desperdício | Descrição |
|---|---|
| Espera | Tempo ocioso entre atividades |
| Transporte | Movimentação desnecessária de materiais |
| Estoque | Acúmulo além do necessário |
| Retrabalho | Correção de defeitos e erros |
| Excesso de processamento | Etapas que não agregam valor |
| Movimentação | Deslocamento desnecessário de pessoas |
| Produção excessiva | Produzir além da demanda |
| Talentos não aproveitados | Subutilização de habilidades |

**Objetivo:** Entregar mais valor com menos recursos.

## 7. Six Sigma

Foca na redução de defeitos.

Utiliza forte embasamento estatístico.

Ferramentas comuns:

- CEP (Controle Estatístico de Processo)
- Histogramas
- Pareto
- Ishikawa (Diagrama de Causa e Efeito)
- Regressão
- DOE (Design of Experiments)

Muito utilizado em:

- Indústria
- Bancos
- Telecom
- Saúde

## 8. DMAIC

É o método de melhoria do Six Sigma.

As etapas são:

| Fase | Descrição |
|---|---|
| **D**efine | Definir problema |
| **M**easure | Medir desempenho |
| **A**nalyze | Encontrar causas |
| **I**mprove | Implementar melhorias |
| **C**ontrol | Garantir estabilidade |

## 9. Kaizen

Filosofia japonesa.

Busca pequenas melhorias diárias.

Características:

- Participação de todos
- Baixo custo
- Alta frequência
- Melhoria contínua

## 10. IDEF0

Muito utilizada em órgãos públicos e projetos de engenharia.

Cada processo é representado por:

- Entradas
- Saídas
- Controles
- Mecanismos

Permite excelente documentação funcional.

## 11. IDEF3

Complementa a IDEF0.

Mostra:

- Sequência dos processos
- Cenários
- Fluxos
- Eventos

## 12. EPC (Event-driven Process Chain)

Popularizada pelo SAP.

Representa:

```
Evento → Função → Evento → Função
```

Ideal para modelagem de ERPs.

## 13. UML Activity Diagram

Voltada para desenvolvimento de software.

Representa:

- Fluxos
- Paralelismo
- Condições
- Objetos
- Estados

Muito utilizada junto com UML.

## 14. TOGAF

Não é uma metodologia exclusiva de processos.

É uma estrutura de Arquitetura Corporativa.

Inclui:

- Arquitetura de negócios
- Dados
- Aplicações
- Tecnologia

Os processos fazem parte da Arquitetura de Negócios.

## 15. APQC Process Classification Framework (PCF)

É um modelo de referência internacional.

Organiza milhares de processos em categorias padronizadas.

Permite:

- Benchmark
- Comparação entre empresas
- Padronização

Muito usado em grandes organizações.

## 16. SCOR

Especializado em Supply Chain.

Divide a cadeia em:

| Fase | Descrição |
|---|---|
| Plan | Planejar |
| Source | Abastecer |
| Make | Produzir |
| Deliver | Entregar |
| Return | Devolver |
| Enable | Habilitar |

Excelente para logística.

## Comparativo Geral

| Critério | Melhor metodologia |
|---|---|
| Documentar processos | BPMN |
| Processos simples | Fluxograma |
| Visão macro | SIPOC |
| Automação | BPM + BPMN |
| Melhoria contínua | Lean |
| Redução de defeitos | Six Sigma |
| Projetos de melhoria | DMAIC |
| Engenharia de processos | IDEF |
| ERP SAP | EPC |
| Desenvolvimento de software | UML |
| Arquitetura corporativa | TOGAF |
| Benchmark | APQC |
| Cadeia logística | SCOR |
| Fluxo de valor | VSM |

## Qual Metodologia Escolher?

Na prática, as organizações costumam combinar abordagens em vez de adotar apenas uma:

- **Pequenas empresas:** Fluxograma + BPMN.
- **Órgãos públicos:** BPM/BPMN para documentação e automação, complementados por SIPOC para visão inicial e APQC como referência de processos.
- **Indústrias:** Lean + VSM + Six Sigma + DMAIC.
- **Empresas de software:** BPMN para processos de negócio e UML para processos técnicos.
- **Grandes corporações:** TOGAF para arquitetura corporativa, APQC para padronização, BPM/BPMN para gestão de processos e Lean Six Sigma para melhoria contínua.

Em geral, **BPM como disciplina de gestão** e **BPMN como padrão de modelagem** formam a combinação mais difundida no mercado, especialmente quando há interesse em governança, transformação digital e automação de processos por meio de plataformas BPMS ou RPA.
